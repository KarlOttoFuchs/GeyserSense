# GeyserSense
GeyserSense is an ESP32-C3 smart sensor that works with Geyserwise-style NTC thermostat probes. It lets Home Assistant users monitor geyser temperature.  Thus allowing smarter scheduling and control of the geyser heating via Home Assistant — perfect for solar PV optimisation (e.g. heat to 70 °C on midday solar and short morning boosts to 55 °C).
